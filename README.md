# SOCRIS Preview

Previa estatica de site catalogo para a SOCRIS, baseada nas respostas do briefing enviado por Mercia Cristina Passos Lima.

## Como usar

Abra o arquivo `index.html` no navegador.

## Escopo desta versao

- Site estatico em HTML, CSS e JavaScript
- Catalogo inicial com 2 produtos demonstrativos
- Botao direto para WhatsApp
- Link para Instagram
- Layout responsivo para celular
- Secao explicando a evolucao futura para carrinho, pagamento online e frete

## O que editar depois

- Numero do WhatsApp em `js/script.js`
- Produtos, descricoes, tamanhos e precos em `js/script.js`
- Imagens dos produtos em `img/produtos`
- Cores e estilo visual em `css/style.css`
- Textos institucionais em `index.html`

## Observacao comercial

Carrinho, pagamento online e calculo de frete nao fazem parte desta primeira versao. Essas funcionalidades devem ser tratadas como segunda etapa do projeto.
